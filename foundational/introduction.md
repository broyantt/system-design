
There are essentially 4 themes that interviewers will test in all system design interviews. 

## 1. Problem Navigation

- Testing my **ability to break down a highly complex problem** into smaller problems. 
	- Typically *the most difficult part* for new people learning system design.
- Need to be able to **prioritize** the important parts of the problem and focus on them, instead of focusing on any trivial/uninteresting aspects of the problem. 

### 2. Solution Design

- Testing my **ability to actually solve the broken down problems** using knowledge of core concepts. 
- Need to be able to combine these solutions such that it forms a cohesive solution that is:
	- Well-Structured. 
	- Easy to understand. 
	- Doesn't ignore scaling or performance considerations.

### 3. Technical Excellence

- Testing my **ability in how to use key technologies (current and not outdated)** with well-recognized patterns in order to solve the problems. 

### 4. Communication & Collaboration

- Just be confident and friendly lol (don't be defensive and make sure to explain the complex concepts clearly!)
